# DocuMind AI — RAG Chatbot

A Retrieval-Augmented Generation (RAG) chatbot that allows users to upload PDF documents and ask questions based on document content.

## Features
- PDF Upload
- Document Chunking
- FAISS Vector Database
- HuggingFace Embeddings
- Ollama Local LLM
- React Frontend
- FastAPI Backend

## Tech Stack
- React.js
- FastAPI
- LangChain
- FAISS
- Ollama
- HuggingFace Embeddings
- PyMuPDF

## Run Backend

cd backend
uvicorn main:app --reload

## Run Frontend

cd frontend
npm start
